## Map Notes Application

This project is an application where users can create notes at specific locations on a map. It allows users to click on the map to add notes and save them locally using **localStorage**.

### Features:

- Users can click on any location on the map to add a note.
- Notes contain information like title, date, and status.
- Added notes are saved using **localStorage**, so they persist even after a page refresh.
- A marker is shown on the map for each added note.
- Users can delete or edit notes.

### Technologies Used:

- **Leaflet.js**: For map integration and interactions.
- **JavaScript**: Application logic and user interactions.
- **HTML/CSS**: Page structure and visual design.
- **localStorage**: To store user notes in the browser.

### Usage:

- Click on any point on the map to add a new note.
- Each note will include a title, date, and status.
- After saving the note, a marker will be placed on the map at the note's location.
- Notes continue to be saved even after a page refresh.
